Google Apps Script (GAS) 連携・Web API設定

お持ちのGASでデプロイしたWebアプリURLを入力・保存することで、本番のスプレッドシートと直接連携できます。

スプレッドシートの「貸出返却履歴」シートから直近1ヵ月（30日間）の集計データをリアルタイムでグラフ表示します。コード更新時は「新バージョン」で再デプロイを行ってください。

// doGetにgetDashboardData(ss)が含まれているか確認してください
function doGet(e) {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  const action = (e && e.parameter) ? e.parameter.action : "";
  if (action === "getDashboardData") {
    return ContentService.createTextOutput(JSON.stringify(getDashboardData(ss)))
      .setMimeType(ContentService.MimeType.JSON);
  }
  // ...既存の処理...
}

デプロイの確認手順

  • ウェブアプリのアクセス権限: 「全員 (Anyone)」
  • デプロイ更新時: 「デプロイを管理」 ＞ 「編集」 ＞ 「新バージョン」 を選択
